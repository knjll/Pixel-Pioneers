# 📸 Pixel Pioneers (FRONTEND ONLY)

_This project was built in 2024 as a part of academic project submission_

A photography website(frontend) built with HTML, CSS, JavaScript to showcase the photographer's talent and creative vision through a visually stunning and user-friendly online platform.

## Features
- Modern, minimalist style, focusing on visuals, with easy navigation to other sections of the site.
- A categorized gallery to showcase different types of photography (e.g., Wedding, fashion, events).
- A brief bio of the photographer's expertise, experience, and contact.
  
_All assets used in this project have been taken from online sources. Any resemblance to real life is purely coincidental_
